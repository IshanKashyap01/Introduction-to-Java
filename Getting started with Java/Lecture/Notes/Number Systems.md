# Number Systems

## Hexadecimal

- Hexadecimal is a base 16 number system meant to simplify binary numbers

- It has sixteen numbers starting from $0$ to $9$ followed by `A` to `F`

- To convert binary to hexadecimal,

    1. Club binary digits into groups of four

    2. Convert each group to its hexadecimal equivalent

- For example, `1010 0001` will be `A1`

## Octal

- Octal is a base 8 number system, which contains 8 digits from `0` to `7`

- For example, $8$ in octal is will be `10`
